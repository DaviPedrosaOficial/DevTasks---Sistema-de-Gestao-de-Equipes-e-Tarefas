# DevTasks---Sistema-de-Gestao-de-Equipes-e-Tarefas
O DevTasks é uma plataforma web de gerenciamento de tarefas e equipes, inspirada em ferramentas como Trello, Jira e Notion.  O sistema permite que usuários criem equipes, organizem projetos e gerenciem tarefas de forma colaborativa, utilizando autenticação segura, permissões de acesso e organização por status e prioridades.
